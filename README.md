Changing the exec line in the .desktop file in "~/.local/share/applications/" to 
Exec=omarchy-launch-webapp https://wordswithfriends.com/ --load-extension=/home/username/path/to/wwf-ext 
will load the script on launch

There is also a way to launch it with keybindings

If all this fails, you can always install the extension via chrome://extensions
